## New Requirements

- **20 Advanced (Hard) exercises** focusing on:
  - Edge cases and exceptions
  - Common native-speaker traps
  - Multiple grammar points combined
  - Subtle distinctions
  - Context-dependent scenarios
  - Tricky vocabulary patterns

### Per Exercise - Comprehensive Explanation Format
Every exercise MUST have:
1. Clear question in Hebrew
2. Correct answer
3. **Comprehensive explanation** with ALL four components:
   - **תשובה נכונה:** (Correct answer) - State the correct answer explicitly
   - **כלל:** (Rule) - Explain the relevant grammar rule in detail
   - **שים לב:** (Pay attention) - Highlight important points or nuances
   - **טעות נפוצה:** (Common mistake) - Explain what students often get wrong

**Example:**
```
"תשובה נכונה: tomatoes. כלל: שמות עצם המסתיימים ב-O אחרי עיצור מוסיפים -ES.
שים לב: אל תוסיף רק S, זו טעות נפוצה. חריגים: photo → photos, piano → pianos.
טעות נפוצה: לכתוב tomatos ללא ES."
```

## Exercise Creation Guidelines

### Advanced/Hard Level (20 exercises per lesson)

**Characteristics:**
- Edge cases and exceptions (roof → roofs, not rooves)
- Native-speaker level traps (chief → chiefs, not chieves)
- Multiple grammar points tested
- Subtle distinctions (volcano → volcanoes/volcanos - both acceptable)
- Context-dependent scenarios
- Tricky vocabulary patterns

**Example Topics:**
1. Exception cases (person → people, photo → photos not photoes)
2. Irregular plurals in compound nouns
3. Prepositions that change meaning entirely
4. Time expressions with slight differences (in time vs on time)
5. Stative vs dynamic verb usage
6. Articles with abstract/uncountable nouns in specific contexts
7. Word order with multiple prepositions
8. Formal vs informal structures
9. American vs British differences
10. Idioms using the grammar point

**Explanation Format (MANDATORY for every exercise):**

Each exercise MUST include ALL four components:

1. **תשובה נכונה:** - State the correct answer explicitly
2. **כלל:** - Explain the relevant grammar rule in detail
3. **שים לב:** - Highlight important points or nuances
4. **טעות נפוצה:** - Explain what students often get wrong

**Example:**
```
"תשובה נכונה: roofs. כלל: למרות שרוב המילים המסתיימות ב-F משנות ל-VES,
roof הוא חריג ומקבל רק S. שים לב: חריגים נוספים - chef → chefs, belief → beliefs.
טעות נפוצה: לכתוב rooves על פי הכלל הרגיל."
```

**Multiple Choice Distractors:**
- All grammatically possible in other contexts
- Very subtle meaning differences
- Tests understanding vs memorization
- Common advanced-learner errors

**Fill in Blank:**
- Requires deep grammar understanding
- Context provides sufficient clues
- Tests nuanced meaning
- Natural vs textbook language
