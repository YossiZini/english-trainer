# Video Scripts - English Grammar Topics
## תסריטי וידאו - נושאי דקדוק באנגלית

This folder contains Hebrew video scripts for all grammar topics in the English learning platform. Each script is designed for ages 10-12 and includes theory, examples, common mistakes, and practice exercises.

תיקייה זו מכילה תסריטי וידאו בעברית לכל נושאי הדקדוק בפלטפורמת לימוד האנגלית. כל תסריט מיועד לגילאי 10-12 וכולל תיאוריה, דוגמאות, טעויות נפוצות ותרגולים.

## Script Format (תבנית התסריט)

Each video script includes:
- **Opening** (30 sec): Hook and overview
- **Rule Explanation** (2-3 min): Theory and structure
- **Examples** (2-3 min): 3-5 examples with translations
- **Common Mistakes** (1-2 min): 2-3 common errors
- **Quick Practice** (1 min): 2-3 practice sentences
- **Summary** (30 sec): Key takeaways

Total video length: ~6-8 minutes per sub-topic
