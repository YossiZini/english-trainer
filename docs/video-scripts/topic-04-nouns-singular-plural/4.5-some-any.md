# 4.5 - Some ו-Any | Some and Any

## פתיחה (30 שניות)

שלום! היום נלמד על שתי מילים קטנות אבל חשובות מאוד - **some** ו-**any**!

שתי המילים האלה אומרות "קצת" או "כמה", אבל מתי משתמשים ב-some ומתי ב-any? יש כלל פשוט! בואו נלמד מתי להשתמש בכל אחת מהמילים האלה, עם דוגמאות ותרגול!

## הסבר הכלל (2-3 דקות)

### מה זה Some ו-Any?

**some** ו-**any** משמשים כשאנחנו מדברים על **כמות לא מדויקת** - "כמה", "קצת", "אילו".

### החוק הבסיסי:

| מילה | מתי משתמשים | דוגמה |
|------|-------------|--------|
| **SOME** | משפטים חיוביים | I have **some** books. |
| **ANY** | שאלות ושלילות | Do you have **any** books? |
|  |  | I don't have **any** books. |

### שימוש ב-SOME:

**1. משפטים חיוביים (Affirmative sentences):**

עם countable (בני ספירה ברבים):
- I have **some** books. (יש לי כמה ספרים)
- There are **some** apples. (יש כמה תפוחים)
- She has **some** friends. (יש לה כמה חברים)

עם uncountable (לא בני ספירה):
- I need **some** water. (אני צריך קצת מים)
- There is **some** milk. (יש קצת חלב)
- She wants **some** coffee. (היא רוצה קצת קפה)

**2. הצעות ובקשות (Offers and Requests):**
גם בשאלות, אם זו הצעה או בקשה:
- Would you like **some** tea? (תרצה קצת תה? - הצעה)
- Can I have **some** water? (אפשר קצת מים? - בקשה)

### שימוש ב-ANY:

**1. שאלות (Questions):**

עם countable:
- Do you have **any** books? (יש לך ספרים?)
- Are there **any** apples? (יש תפוחים?)
- Does she have **any** friends? (יש לה חברים?)

עם uncountable:
- Do you need **any** water? (אתה צריך מים?)
- Is there **any** milk? (יש חלב?)
- Does she want **any** coffee? (היא רוצה קפה?)

**2. משפטים שליליים (Negative sentences):**

עם countable:
- I don't have **any** books. (אין לי ספרים)
- There aren't **any** apples. (אין תפוחים)
- She doesn't have **any** friends. (אין לה חברים)

עם uncountable:
- I don't need **any** water. (אני לא צריך מים)
- There isn't **any** milk. (אין חלב)
- She doesn't want **any** coffee. (היא לא רוצה קפה)

### טבלת סיכום:

| סוג משפט | Countable (רבים) | Uncountable |
|---------|------------------|-------------|
| **חיובי (+)** | some books | some water |
| **שלילי (-)** | any books | any water |
| **שאלה (?)** | any books? | any water? |
| **הצעה/בקשה** | some tea? | some coffee? |

## דוגמאות (2-3 דקות)

### דוגמה 1 - Some במשפט חיובי (countable):
**English:** I have some friends in Tel Aviv.
**Hebrew:** יש לי כמה חברים בתל אביב.
**הסבר:** משפט חיובי + countable (friends) = some.

### דוגמה 2 - Some במשפט חיובי (uncountable):
**English:** There is some milk in the fridge.
**Hebrew:** יש קצת חלב במקרר.
**הסבר:** משפט חיובי + uncountable (milk) = some.

### דוגמה 3 - Any בשאלה (countable):
**English:** Do you have any brothers or sisters?
**Hebrew:** יש לך אחים או אחיות?
**הסבר:** שאלה + countable (brothers, sisters) = any.

### דוגמה 4 - Any בשאלה (uncountable):
**English:** Is there any sugar in the cupboard?
**Hebrew:** יש סוכר בארון?
**הסבר:** שאלה + uncountable (sugar) = any.

### דוגמה 5 - Any במשפט שלילי (countable):
**English:** I don't have any pets.
**Hebrew:** אין לי חיות מחמד.
**הסבר:** שלילה (don't have) + countable (pets) = any.

### דוגמה 6 - Any במשפט שלילי (uncountable):
**English:** There isn't any coffee left.
**Hebrew:** לא נשאר קפה.
**הסבר:** שלילה (isn't) + uncountable (coffee) = any.

### דוגמה 7 - Some בהצעה:
**English:** Would you like some cake?
**Hebrew:** תרצה קצת עוגה?
**הסבר:** הצעה = some (גם בשאלה!). זו הצעה נחמדה, לא שאלה רגילה.

## טעויות נפוצות (1-2 דקות)

### טעות 1: some במשפט שלילי
❌ I don't have some money.
✅ I don't have any money.
**למה?** במשפט שלילי צריך any (לא some!).

### טעות 2: any במשפט חיובי רגיל
❌ I have any books.
✅ I have some books.
**למה?** במשפט חיובי צריך some (לא any!).

### טעות 3: any בהצעה
❌ Would you like any tea?
✅ Would you like some tea?
**למה?** בהצעות משתמשים ב-some, גם אם זו שאלה!

### טעות 4: some בשאלה רגילה
❌ Do you have some books?
✅ Do you have any books?
**למה?** בשאלה רגילה צריך any. some רק בהצעות/בקשות!

### טעות 5: לשכוח any במשפט שלילי
❌ I don't have money.
✅ I don't have any money.
**למה?** במשפט שלילי רצוי להוסיף any (אפשר גם בלי, אבל עם any יותר נכון).

## תרגול קצר (1 דקה)

בחרו some או any:

**1.** I have ___ apples. (משפט חיובי)
- ✅ some (חיובי = some)

**2.** Do you have ___ questions? (שאלה)
- ✅ any (שאלה = any)

**3.** There isn't ___ milk. (שלילה)
- ✅ any (שלילה = any)

**4.** Would you like ___ coffee? (הצעה)
- ✅ some (הצעה = some)

**5.** She doesn't have ___ friends. (שלילה)
- ✅ any (שלילה = any)

## סיכום (30 שניות)

היום למדנו על **some ו-any**:
- **SOME** במשפטים **חיוביים**: I have some books
- **ANY** ב**שאלות**: Do you have any books?
- **ANY** ב**שלילות**: I don't have any books
- **SOME** ב**הצעות/בקשות** (גם בשאלה!): Would you like some tea?
- עובד עם **countable ו-uncountable**
- כלל זהב: חיובי = some, שאלה/שלילה = any

בשיעור הבא נסכם את כל הטעויות הנפוצות עם שמות עצם! נתראה!
