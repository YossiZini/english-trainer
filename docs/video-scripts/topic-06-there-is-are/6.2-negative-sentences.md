# 6.2 - משפטים שליליים | Negative Sentences with There is/are

## פתיחה (30 שניות)

שלום שוב! בשיעור הקודם למדנו איך להגיד "יש" באנגלית עם There is ו-There are.

עכשיו בואו נלמד איך להגיד "אין" - משפטים שליליים! זה פשוט מאוד - פשוט מוסיפים NOT. בואו נראה איך!

## הסבר הכלל (2-3 דקות)

### איך עושים שלילה?

בשלילה, פשוט מוסיפים **NOT** אחרי is או are:
- There is + NOT = There is not / There isn't
- There are + NOT = There are not / There aren't

### טבלת צורות שליליות:

| Affirmative | Negative (Full) | Negative (Short) | Hebrew |
|-------------|----------------|------------------|---------|
| There is | There is not | **There isn't** | אין |
| There are | There are not | **There aren't** | אין |

### מבנה המשפט השלילי:

**There isn't/aren't + noun + (place/time)**

```
There isn't + a/an/one + singular noun
There isn't + any + uncountable noun
There aren't + any + plural noun
```

### נקודות חשובות:

**1. There isn't עם יחיד:**
- There isn't a dog. (אין כלב)
- There isn't one teacher. (אין מורה אחד)
- There isn't an apple. (אין תפוח)

**2. There isn't עם uncountable:**
- There isn't water. (אין מים)
- There isn't any milk. (אין חלב)
- There isn't time. (אין זמן)

**3. There aren't עם רבים:**
- There aren't dogs. (אין כלבים)
- There aren't three teachers. (אין שלושה מורים)
- There aren't any apples. (אין תפוחים)

**4. Any בשלילה:**
- בשלילה, לרוב משתמשים ב-**any** (לא some!)
- There isn't any water. (אין מים כלל)
- There aren't any chairs. (אין כיסאות כלל)

## דוגמאות (2-3 דקות)

### דוגמה 1 - There isn't עם a:
**English:** There isn't a cat in the garden.
**Hebrew:** אין חתול בגינה.
**הסבר:** אין חתול (יחיד), לכן There isn't. זה ההפך של There is a cat.

### דוגמה 2 - There isn't any עם uncountable:
**English:** There isn't any water in the bottle.
**Hebrew:** אין מים בבקבוק.
**הסבר:** water = uncountable, לכן isn't. שימו לב ל-any בשלילה.

### דוגמה 3 - There aren't עם מספר:
**English:** There aren't three dogs in the park.
**Hebrew:** אין שלושה כלבים בפארק.
**הסבר:** three dogs = רבים, לכן There aren't.

### דוגמה 4 - There aren't any עם רבים:
**English:** There aren't any students in the class.
**Hebrew:** אין תלמידים בכיתה.
**הסבר:** students = רבים, לכן aren't. משתמשים ב-any כי זה שלילה.

### דוגמה 5 - There isn't a problem:
**English:** There isn't a problem.
**Hebrew:** אין בעיה.
**הסבר:** problem = יחיד, לכן isn't. ביטוי נפוץ מאוד!

### דוגמה 6 - There aren't many:
**English:** There aren't many people here.
**Hebrew:** אין הרבה אנשים כאן.
**הסבר:** people = רבים (תמיד!), לכן aren't. many עובד טוב בשלילה.

### דוגמה 7 - תיאור חדר:
**English:** There isn't a TV and there aren't any books in my room.
**Hebrew:** אין טלוויזיה ואין ספרים בחדר שלי.
**הסבר:** טלוויזיה = יחיד (isn't), ספרים = רבים (aren't any).

## טעויות נפוצות (1-2 דקות)

### טעות 1: להשתמש ב-aren't עם יחיד
❌ There aren't a book on the table.
✅ There isn't a book on the table.
**למה?** a book = יחיד, לכן isn't ולא aren't!

### טעות 2: להשתמש ב-isn't עם רבים
❌ There isn't three dogs.
✅ There aren't three dogs.
**למה?** three dogs = רבים, לכן aren't ולא isn't!

### טעות 3: להשתמש ב-some בשלילה
❌ There aren't some chairs.
✅ There aren't any chairs.
**למה?** בשלילה משתמשים ב-any, לא some!

### טעות 4: לשכוח את NOT
❌ There is a problem.
✅ There isn't a problem.
**למה?** אם רוצים לומר "אין", חייבים isn't/aren't (עם not)!

### טעות 5: מיקום שגוי של not
❌ There not is a book.
✅ There isn't a book.
**למה?** not בא אחרי is/are, לא לפני! הקיצור isn't/aren't הוא הנכון.

## תרגול קצר (1 דקה)

הפכו לשלילה:

**1.** There is a cat under the bed.
- ✅ There isn't a cat under the bed.

**2.** There are five apples.
- ✅ There aren't five apples.

**3.** There is milk in the fridge.
- ✅ There isn't any milk in the fridge.

**4.** There are many people.
- ✅ There aren't many people.

**5.** There is one teacher.
- ✅ There isn't one teacher.

## סיכום (30 שניות)

היום למדנו:
- **There isn't** עם יחיד ו-uncountable
- **There aren't** עם רבים
- מוסיפים **not** אחרי is/are (קיצור: isn't/aren't)
- משתמשים ב-**any** בשלילה (לא some)
- המבנה: There isn't/aren't + (any) + noun

בשיעור הבא נלמד איך לשאול שאלות עם There is/are. נתראה!
