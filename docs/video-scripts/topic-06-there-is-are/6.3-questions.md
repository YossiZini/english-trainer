# 6.3 - שאלות | Questions with There is/are

## פתיחה (30 שניות)

שלום! עד עכשיו למדנו איך להגיד "יש" ו"אין" באנגלית.

עכשיו בואו נלמד איך לשאול "יש?" - איך הופכים There is/are לשאלה. זה מאוד פשוט - פשוט משנים את הסדר! בואו נראה.

## הסבר הכלל (2-3 דקות)

### איך יוצרים שאלה?

בשאלה, **מחליפים את הסדר** בין There ל-is/are:
- There is → **Is there**?
- There are → **Are there**?

### טבלת שאלות:

| Statement | Question | Hebrew |
|-----------|----------|---------|
| There is a book. | **Is there** a book? | יש ספר? |
| There are books. | **Are there** books? | יש ספרים? |

### מבנה השאלה:

**Is/Are there + noun + (place/time)?**

```
Is there + a/an/one + singular noun?
Is there + any + uncountable noun?
Are there + any + plural noun?
```

### נקודות חשובות:

**1. Is there עם יחיד:**
- Is there a dog? (יש כלב?)
- Is there one teacher? (יש מורה אחד?)
- Is there an apple? (יש תפוח?)

**2. Is there עם uncountable:**
- Is there water? (יש מים?)
- Is there any milk? (יש חלב?)
- Is there time? (יש זמן?)

**3. Are there עם רבים:**
- Are there dogs? (יש כלבים?)
- Are there three teachers? (יש שלושה מורים?)
- Are there any apples? (יש תפוחים?)

**4. Any בשאלות:**
- בשאלות, לרוב משתמשים ב-**any** (לא some!)
- Is there any water? (יש מים?)
- Are there any chairs? (יש כיסאות?)

## דוגמאות (2-3 דקות)

### דוגמה 1 - Is there a:
**English:** Is there a cat in the garden?
**Hebrew:** יש חתול בגינה?
**הסבר:** שואלים על חתול אחד (יחיד), לכן Is there. סדר המילים: Is there + a cat.

### דוגמה 2 - Is there any עם uncountable:
**English:** Is there any water in the bottle?
**Hebrew:** יש מים בבקבוק?
**הסבר:** water = uncountable, לכן Is there. משתמשים ב-any בשאלה.

### דוגמה 3 - Are there עם מספר:
**English:** Are there three dogs in the park?
**Hebrew:** יש שלושה כלבים בפארק?
**הסבר:** three dogs = רבים, לכן Are there. המספר בא אחרי there.

### דוגמה 4 - Are there any:
**English:** Are there any students in the class?
**Hebrew:** יש תלמידים בכיתה?
**הסבר:** students = רבים, לכן Are there. any נפוץ מאוד בשאלות!

### דוגמה 5 - Is there a problem:
**English:** Is there a problem?
**Hebrew:** יש בעיה?
**הסבר:** problem = יחיד, לכן Is there. שאלה נפוצה מאוד!

### דוגמה 6 - Are there many:
**English:** Are there many people here?
**Hebrew:** יש הרבה אנשים כאן?
**הסבר:** people = רבים (תמיד!), לכן Are there. many עובד מצוין בשאלות.

### דוגמה 7 - בחנות:
**English:** Excuse me, is there a bathroom here?
**Hebrew:** סליחה, יש כאן שירותים?
**הסבר:** שאלה מעשית שתשתמשו בה הרבה! bathroom = יחיד, לכן Is there.

## טעויות נפוצות (1-2 דקות)

### טעות 1: להשתמש ב-Are there עם יחיד
❌ Are there a book?
✅ Is there a book?
**למה?** a book = יחיד, לכן Is there ולא Are there!

### טעות 2: להשתמש ב-Is there עם רבים
❌ Is there three dogs?
✅ Are there three dogs?
**למה?** three dogs = רבים, לכן Are there ולא Is there!

### טעות 3: לשכוח להחליף את הסדר
❌ There is a problem?
✅ Is there a problem?
**למה?** בשאלה חייבים להחליף: Is there (לא There is)!

### טעות 4: להשתמש ב-some בשאלות
❌ Are there some chairs?
✅ Are there any chairs?
**למה?** בשאלות משתמשים ב-any, לא some!

### טעות 5: לשכוח את There
❌ Is a book on the table?
✅ Is there a book on the table?
**למה?** בעברית אומרים רק "יש", אבל באנגלית חייבים there אחרי is/are!

## תרגול קצר (1 דקה)

הפכו לשאלה:

**1.** There is a cat under the bed.
- ✅ Is there a cat under the bed?

**2.** There are five apples.
- ✅ Are there five apples?

**3.** There is milk in the fridge.
- ✅ Is there any milk in the fridge?

**4.** There are many people.
- ✅ Are there many people?

**5.** There is one teacher.
- ✅ Is there one teacher?

## סיכום (30 שניות)

היום למדנו:
- **Is there** לשאלות עם יחיד ו-uncountable
- **Are there** לשאלות עם רבים
- **מחליפים את הסדר**: There is → Is there
- משתמשים ב-**any** בשאלות (לא some)
- המבנה: Is/Are there + (any) + noun?

בשיעור הבא נלמד איך לענות בקצרה על שאלות כאלה - תשובות קצרות! נתראה!
