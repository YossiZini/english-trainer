# 6.7 - טעויות נפוצות | Common Mistakes with There is/are

## פתיחה (30 שניות)

שלום! סיימנו את כל הכללים של There is/are.

היום נסכם את כל הטעויות הנפוצות שתלמידים עושים עם המבנה הזה. אם תיזהרו מהטעויות האלה, השימוש שלכם יהיה מושלם! בואו נתחיל.

## הסבר הכלל (2-3 דקות)

### למה עושים טעויות עם There is/are?

**1. בעברית יש רק "יש" אחד**
- בעברית: יש ספר, יש ספרים (אותה מילה!)
- באנגלית: There **is** a book, There **are** books (שונה!)

**2. המבנה שונה מעברית**
- בעברית: "יש ספר על השולחן"
- באנגלית: "There is a book on the table"

**3. בלבול עם Have**
- בעברית: "יש לי ספר" (יש)
- באנגלית: "I have a book" (לא there is!)

### טבלת הטעויות הנפוצות ביותר:

| טעות | למה זה שגוי | תיקון |
|------|-------------|-------|
| There are a book | are = רבים, book = יחיד | There **is** a book |
| There is three dogs | is = יחיד, three = רבים | There **are** three dogs |
| Is there books? | books = רבים, צריך are | **Are** there books? |
| There isn't books | books = רבים, צריך aren't | There **aren't** books |
| There have a problem | have לא מתאים כאן | There **is** a problem |

## דוגמאות (2-3 דקות)

### טעות 1 - בלבול בין is ל-are (יחיד/רבים):

**❌ שגוי:** There are a book on the table.
**✅ נכון:** There is a book on the table.
**למה?** "a book" = יחיד, לכן צריך is (לא are)!

**❌ שגוי:** There is many students in the class.
**✅ נכון:** There are many students in the class.
**למה?** "students" = רבים, לכן צריך are (לא is)!

### טעות 2 - בלבול עם people:

**❌ שגוי:** There is many people here.
**✅ נכון:** There are many people here.
**למה?** "people" = רבים תמיד! (אפילו שלא נגמר ב-s)

**❌ שגוי:** There is three people.
**✅ נכון:** There are three people.
**למה?** people = רבים, גם עם מספר!

### טעות 3 - שלילה שגויה:

**❌ שגוי:** There isn't any books.
**✅ נכון:** There aren't any books.
**למה?** books = רבים, צריך aren't (לא isn't)!

**❌ שגוי:** There aren't a dog.
**✅ נכון:** There isn't a dog.
**למה?** a dog = יחיד, צריך isn't (לא aren't)!

### טעות 4 - שאלות שגויות:

**❌ שגוי:** Is there any chairs?
**✅ נכון:** Are there any chairs?
**למה?** chairs = רבים, צריך Are (לא Is)!

**❌ שגוי:** Are there a problem?
**✅ נכון:** Is there a problem?
**למה?** a problem = יחיד, צריך Is (לא Are)!

### טעות 5 - שכחת There:

**❌ שגוי:** Is a book on the table?
**✅ נכון:** Is there a book on the table?
**למה?** חייבים there אחרי is/are בשאלה!

**❌ שגוי:** In my room is a bed.
**✅ נכון:** In my room there is a bed.
**למה?** חייבים there לפני is!

### טעות 6 - שימוש ב-have במקום there is:

**❌ שגוי:** There have a problem.
**✅ נכון:** There is a problem.
**למה?** "יש" = there is, לא have! (have = יש לי)

**❌ שגוי:** In the park have many trees.
**✅ נכון:** In the park there are many trees.
**למה?** כשמתארים מקום, משתמשים ב-there is/are!

### טעות 7 - some/any במקום הלא נכון:

**❌ שגוי:** Are there some books?
**✅ נכון:** Are there any books?
**למה?** בשאלות משתמשים ב-any, לא some!

**❌ שגוי:** There aren't some chairs.
**✅ נכון:** There aren't any chairs.
**למה?** בשלילה משתמשים ב-any, לא some!

## טעויות נפוצות (1-2 דקות)

### קטגוריה 1: טעויות עם uncountable nouns

**❌ שגוי:** There are water in the bottle.
**✅ נכון:** There is water in the bottle.
**למה?** water = uncountable, תמיד is!

**❌ שגוי:** Are there any milk?
**✅ נכון:** Is there any milk?
**למה?** milk = uncountable, צריך is!

### קטגוריה 2: טעויות עם מספרים

**❌ שגוי:** There is five books.
**✅ נכון:** There are five books.
**למה?** 5 = יותר מאחד, תמיד are!

**❌ שגוי:** There are one student.
**✅ נכון:** There is one student.
**למה?** one = יחיד, תמיד is!

### קטגוריה 3: טעויות בתשובות קצרות

**❌ שגוי:** Is there a cat? → Yes, it is.
**✅ נכון:** Is there a cat? → Yes, there is.
**למה?** עונים עם there, לא עם it!

**❌ שגוי:** Are there books? → Yes, there is.
**✅ נכון:** Are there books? → Yes, there are.
**למה?** השאלה עם are, התשובה גם עם are!

## תרגול קצר (1 דקה)

מצאו וצרו את הטעות:

**1.** ❌ There are a dog in the garden.
- ✅ There is a dog in the garden. (dog = יחיד)

**2.** ❌ Is there any books?
- ✅ Are there any books? (books = רבים)

**3.** ❌ There isn't many people.
- ✅ There aren't many people. (people = רבים)

**4.** ❌ In the room have a table.
- ✅ In the room there is a table. (צריך there is)

**5.** ❌ Are there some water?
- ✅ Is there any water? (water = uncountable + any בשאלה)

## סיכום (30 שניות)

סיכום הטעויות הנפוצות ביותר:
1. **is/are**: להתאים לפי יחיד/רבים (a book = is, books = are)
2. **people**: תמיד רבים! (are, not is)
3. **uncountable**: תמיד is! (water, milk, money)
4. **שאלות/שלילה**: להתאים את is/are גם בשלילה ובשאלות
5. **There**: תמיד צריך there! (לא רק is/are)
6. **have vs there is**: יש (במקום) = there is, יש לי = I have
7. **some/any**: חיובי = some, שאלה/שלילה = any

עכשיו אתם מוכנים להשתמש ב-There is/are בצורה מושלמת! המשיכו לתרגל!
