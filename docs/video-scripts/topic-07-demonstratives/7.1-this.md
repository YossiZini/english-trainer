# 7.1 - This - זה/זאת (יחיד, קרוב) | This - Singular, Near

## פתיחה (30 שניות)

שלום לכולם! היום אנחנו מתחילים נושא חשוב - **Demonstratives** - מילות הצבעה!

מילות הצבעה הן המילים שמשתמשים בהן כדי להצביע על דברים. היום נתמקד ב-**This** - המילה שמשתמשים בה כשמצביעים על דבר אחד שקרוב אלינו. בואו נלמד!

## הסבר הכלל (2-3 דקות)

### מה זה This?

**This** היא מילת הצבעה שמשתמשים בה כדי להצביע על דבר **אחד** (יחיד) ש**קרוב** אלינו.

### טבלת שימוש ב-This:

| Feature | Rule | Hebrew |
|---------|------|---------|
| **Number** | Singular (יחיד) | רק דבר אחד |
| **Distance** | Near (קרוב) | קרוב אלי |
| **Hebrew** | זה / זאת | תלוי בהקשר |

### שני שימושים של This:

**1. כתואר (Adjective) - לפני שם עצם:**
```
This + singular noun
This book (הספר הזה)
This car (המכונית הזאת)
```

**2. כשם גוף (Pronoun) - עומד לבד:**
```
This is...
This is my book. (זה הספר שלי)
This is important. (זה חשוב)
```

### נקודות חשובות:

**1. This עם A/AN:**
- ❌ This a book (שגוי!)
- ✅ This book (נכון!)
- כש-This בא לפני שם, לא צריך a/an!

**2. This עם הפועל to be:**
- This **is** my pen. (זה העט שלי)
- This **is** red. (זה אדום)
- תמיד is (לא are) כי זה יחיד!

**3. This = קרוב:**
- כשהדבר **קרוב אלי** או **בידיים שלי**
- זה משהו שאני יכול לגעת בו

## דוגמאות (2-3 דקות)

### דוגמה 1 - This + noun (תואר):
**English:** This book is very interesting.
**Hebrew:** הספר הזה מאוד מעניין.
**הסבר:** This לפני book (שם עצם). הספר קרוב אלי, אני יכול להחזיק אותו.

### דוגמה 2 - This is (כינוי):
**English:** This is my friend Tom.
**Hebrew:** זה החבר שלי טום.
**הסבר:** This is משמש כדי להציג מישהו. זה מאוד נפוץ בהיכרות!

### דוגמה 3 - This + adjective:
**English:** This apple is red.
**Hebrew:** התפוח הזה אדום.
**הסבר:** This apple (התפוח הזה) + is red (אדום). התפוח קרוב, אני מחזיק אותו.

### דוגמה 4 - This במסעדה:
**English:** I like this pizza!
**Hebrew:** אני אוהב את הפיצה הזאת!
**הסבר:** הפיצה על השולחן שלי (קרובה), לכן This.

### דוגמה 5 - This בחנות:
**English:** How much is this shirt?
**Hebrew:** כמה עולה החולצה הזאת?
**הסבר:** מצביע על חולצה ספציפית בחנות (קרובה אלי).

### דוגמה 6 - This is + adjective:
**English:** This is beautiful!
**Hebrew:** זה יפה!
**הסבר:** This is עומד לבד, מתייחס למשהו שאני רואה (ללא שם עצם אחריו).

### דוגמה 7 - בטלפון:
**English:** Hello, this is David speaking.
**Hebrew:** שלום, דוד מדבר.
**הסבר:** ביטוי מיוחד בטלפון! "This is" משמש כדי להציג את עצמך.

## טעויות נפוצות (1-2 דקות)

### טעות 1: להוסיף a/an אחרי This
❌ This a book is good.
✅ This book is good.
**למה?** This כבר מראה שזה ספציפי, לא צריך a/an!

### טעות 2: להשתמש ב-This עם רבים
❌ This books are mine.
✅ This book is mine. (יחיד)
✅ These books are mine. (רבים)
**למה?** This רק ליחיד! לרבים יש These.

### טעות 3: להשתמש ב-are במקום is
❌ This is my friends.
✅ This is my friend. (יחיד)
✅ These are my friends. (רבים)
**למה?** This = יחיד, לכן is (לא are)!

### טעות 4: להשתמש ב-This עם דברים רחוקים
❌ Look at this mountain! (הר רחוק)
✅ Look at that mountain!
**למה?** This = קרוב. דברים רחוקים = That.

### טעות 5: לשכוח is אחרי This
❌ This my book.
✅ This is my book.
**למה?** צריך פועל (is) כשאין שם עצם אחרי This!

## תרגול קצר (1 דקה)

בחרו את המשפט הנכון:

**1.** הספר הזה (בידיים שלי):
- ✅ This book

**2.** זה העט שלי (מחזיק אותו):
- ✅ This is my pen.

**3.** התפוח הזה אדום (על השולחן שלי):
- ✅ This apple is red.

**4.** כמה עולה? (מצביע על משהו בחנות):
- ✅ How much is this?

**5.** זה החבר שלי (הצגה):
- ✅ This is my friend.

## סיכום (30 שניות)

היום למדנו:
- **This** = יחיד (אחד) + קרוב
- שני שימושים: **This book** (תואר) או **This is** (כינוי)
- תמיד **is** (לא are) כי זה יחיד
- **לא צריך a/an** אחרי This
- משתמשים כשהדבר **קרוב אלינו** או בידיים שלנו

בשיעור הבא נלמד על **That** - המילה שמשתמשים בה לדברים רחוקים! נתראה!
