# 7.3 - These - אלה (רבים, קרוב) | These - Plural, Near

## פתיחה (30 שניות)

שלום! למדנו על This (יחיד, קרוב) ו-That (יחיד, רחוק).

היום נלמד מה קורה כשיש **יותר מדבר אחד** שקרוב אלינו - **These**! זו צורת הרבים של This. בואו נלמד!

## הסבר הכלל (2-3 דקות)

### מה זה These?

**These** היא מילת הצבעה שמשתמשים בה כדי להצביע על **כמה דברים** (רבים) ש**קרובים** אלינו.

### טבלת שימוש ב-These:

| Feature | Rule | Hebrew |
|---------|------|---------|
| **Number** | Plural (רבים) | יותר מאחד |
| **Distance** | Near (קרוב) | קרוב אלי |
| **Hebrew** | אלה / האלה | הדברים האלה |

### השוואה: This vs These

| This (יחיד) | These (רבים) |
|-------------|--------------|
| This book | These books |
| This apple | These apples |
| This is my pen | These are my pens |
| This + **is** | These + **are** |

### שני שימושים של These:

**1. כתואר (Adjective) - לפני שם עצם רבים:**
```
These + plural noun
These books (הספרים האלה)
These apples (התפוחים האלה)
```

**2. כשם גוף (Pronoun) - עומד לבד:**
```
These are...
These are my books. (אלה הספרים שלי)
These are beautiful. (אלה יפים)
```

### נקודות חשובות:

**1. These תמיד עם ARE:**
- These **are** my books. (אלה הספרים שלי)
- These **are** red. (אלה אדומים)
- רבים = are (לא is!)

**2. These = רבים + קרוב:**
- כשיש **כמה דברים** קרובים
- כשאני יכול **לגעת בהם** או הם **בידיים שלי**

**3. These עם שמות עצם רבים:**
- These book**s** (עם s!)
- These apple**s** (עם s!)

## דוגמאות (2-3 דקות)

### דוגמה 1 - These + plural noun:
**English:** These books are mine.
**Hebrew:** הספרים האלה שלי.
**הסבר:** מצביע על כמה ספרים קרובים (על השולחן שלי), לכן These.

### דוגמה 2 - These are (הצגה):
**English:** These are my friends.
**Hebrew:** אלה החברים שלי.
**הסבר:** These are משמש להצגת כמה אנשים. נפוץ מאוד!

### דוגמה 3 - These במסעדה:
**English:** These cookies are delicious!
**Hebrew:** העוגיות האלה טעימות!
**הסבר:** העוגיות על השולחן שלי (קרובות + רבים), לכן These.

### דוגמה 4 - These בחנות:
**English:** How much are these shoes?
**Hebrew:** כמה עולות הנעליים האלה?
**הסבר:** מצביע על זוג נעליים בחנות (קרוב + רבים). שימו לב: are (לא is)!

### דוגמה 5 - This vs These:
**English:** This apple is red, but these apples are green.
**Hebrew:** התפוח הזה אדום, אבל התפוחים האלה ירוקים.
**הסבר:** this = יחיד אחד, these = כמה תפוחים. שניהם קרובים!

### דוגמה 6 - These days (ביטוי):
**English:** These days, everyone has a smartphone.
**Hebrew:** בימים אלה (עכשיו), לכולם יש סמארטפון.
**הסבר:** "these days" = ביטוי נפוץ שמשמעו "בימים אלה" / "עכשיו".

### דוגמה 7 - שיחה בכיתה:
**English:** Teacher, what are these?
**Hebrew:** מורה, מה זה? (מצביע על כמה דברים)
**הסבר:** שואלים על כמה דברים קרובים. שימו לב: are (לא is)!

## טעויות נפוצות (1-2 דקות)

### טעות 1: להשתמש ב-is במקום are
❌ These is my books.
✅ These are my books.
**למה?** These = רבים, לכן תמיד are (לא is)!

### טעות 2: להשתמש ב-These עם יחיד
❌ These book is good.
✅ This book is good. (יחיד)
✅ These books are good. (רבים)
**למה?** These רק לרבים! ליחיד יש This.

### טעות 3: לשכוח s בשם העצם
❌ These book are mine.
✅ These books are mine.
**למה?** These = רבים, אז השם צריך להיות ברבים (books)!

### טעות 4: לבלבל בין These ו-Those
❌ These books over there are good. (ספרים רחוקים)
✅ Those books over there are good.
**למה?** "over there" = רחוק, לכן Those (לא These)!

### טעות 5: להוסיף a/an
❌ These a books are mine.
✅ These books are mine.
**למה?** a/an רק ליחיד! לא משתמשים עם These (שהוא רבים).

## תרגול קצר (1 דקה)

בחרו את המשפט הנכון:

**1.** הספרים האלה (על השולחן שלי):
- ✅ These books

**2.** אלה החברים שלי (הצגה):
- ✅ These are my friends.

**3.** הנעליים האלה יפות (בחנות, קרוב):
- ✅ These shoes are beautiful.

**4.** מה אלה? (מצביע על דברים קרובים):
- ✅ What are these?

**5.** בימים אלה (עכשיו):
- ✅ These days

## סיכום (30 שניות)

היום למדנו:
- **These** = רבים (יותר מאחד) + קרוב
- צורת הרבים של **This**
- תמיד עם **ARE** (לא is!)
- שני שימושים: **These books** (תואר) או **These are** (כינוי)
- השם אחרי These צריך להיות **ברבים** (עם s)

בשיעור הבא נלמד על **Those** - לדברים רבים ורחוקים! נתראה!
