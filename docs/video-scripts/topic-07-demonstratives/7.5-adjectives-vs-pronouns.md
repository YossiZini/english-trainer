# 7.5 - תארים מול כינויים | Adjectives vs Pronouns

## פתיחה (30 שניות)

שלום! למדנו את ארבע מילות ההצבעה: This, That, These, Those.

היום נעמיק בהבנה חשובה - יש **שני אופנים** להשתמש במילות האלה: כ**תואר** (Adjective) או כ**כינוי** (Pronoun). בואו נבין מה ההבדל!

## הסבר הכלל (2-3 דקות)

### שני השימושים של מילות ההצבעה:

**1. כתואר (Demonstrative Adjective):**
- בא **לפני שם עצם**
- מתאר את השם
- תמיד עם שם אחריו!

**2. ככינוי (Demonstrative Pronoun):**
- **עומד לבד** (ללא שם עצם)
- מחליף את השם
- בא עם פועל (is/are)

### טבלת ההשוואה:

| As Adjective (תואר) | As Pronoun (כינוי) |
|---------------------|-------------------|
| **Before noun** | **Stands alone** |
| This **book** | This **is** a book |
| That **car** | That **is** a car |
| These **apples** | These **are** apples |
| Those **houses** | Those **are** houses |

### איך לזהות?

**שאלה: "יש שם עצם מיד אחרי?"**
- **כן** → Adjective (תואר)
  - This **book** is good.
- **לא** → Pronoun (כינוי)
  - This **is** good.

### נקודות חשובות:

**1. כתואר - לפני שם עצם:**
```
This/That/These/Those + NOUN + verb
This book is...
Those houses are...
```

**2. ככינוי - עם פועל מיד אחרי:**
```
This/That/These/Those + IS/ARE + ...
This is...
Those are...
```

**3. אותה מילה, שני תפקידים:**
- **This** יכול להיות גם תואר וגם כינוי
- התפקיד תלוי במקום במשפט!

## דוגמאות (2-3 דקות)

### דוגמה 1 - This כתואר vs ככינוי:
**Adjective:** This **book** is interesting.
**Pronoun:** This **is** interesting.
**Hebrew:** הספר הזה מעניין. / זה מעניין.
**הסבר:** בראשון, "book" בא אחרי This (תואר). בשני, מיד בא "is" (כינוי).

### דוגמה 2 - That כתואר vs ככינוי:
**Adjective:** That **house** is expensive.
**Pronoun:** That **is** expensive.
**Hebrew:** הבית ההוא יקר. / זה יקר.
**הסבר:** בראשון, "house" בא אחרי That. בשני, מיד בא "is".

### דוגמה 3 - These כתואר vs ככינוי:
**Adjective:** These **shoes** are comfortable.
**Pronoun:** These **are** comfortable.
**Hebrew:** הנעליים האלה נוחות. / אלה נוחות.
**הסבר:** בראשון, "shoes" בא אחרי These. בשני, מיד בא "are".

### דוגמה 4 - Those כתואר vs ככינוי:
**Adjective:** Those **mountains** are beautiful.
**Pronoun:** Those **are** beautiful.
**Hebrew:** ההרים ההם יפים. / אלה יפים.
**הסבר:** בראשון, "mountains" בא אחרי Those. בשני, מיד בא "are".

### דוגמה 5 - בשיחה (שילוב):
**English:**
- Look at **these cookies**. (adjective)
- **These are** delicious! (pronoun)
**Hebrew:** תראה את העוגיות האלה. אלה טעימות!
**הסבר:** שימוש בשני האופנים באותה שיחה!

### דוגמה 6 - הצגה:
**English:**
- **This** is my friend Tom. (pronoun)
- **This friend** is from Israel. (adjective)
**Hebrew:** זה החבר שלי טום. החבר הזה מישראל.
**הסבר:** הצגה = pronoun. תיאור = adjective.

### דוגמה 7 - בחנות:
**English:**
- I like **this shirt**. (adjective)
- But **this** is too expensive. (pronoun)
**Hebrew:** אני אוהב את החולצה הזאת. אבל זה יקר מדי.
**הסבר:** this shirt = תואר. this is = כינוי.

## טעויות נפוצות (1-2 דקות)

### טעות 1: לשכוח שם עצם אחרי התואר
❌ I like this. (כשרוצים להגיד "החולצה הזאת")
✅ I like this shirt. (adjective - עם שם)
✅ I like this. (pronoun - רק אם ברור על מה מדברים)
**למה?** כתואר צריך שם עצם! ככינוי לא צריך.

### טעות 2: להוסיף שם מיותר
❌ This is book is good.
✅ This book is good. (adjective)
✅ This is a book. (pronoun)
**למה?** לא יכול להיות גם "this" וגם "is" לפני השם!

### טעות 3: סדר מילים שגוי עם כינוי
❌ This book is.
✅ This is a book. (pronoun)
✅ This book is good. (adjective + תואר)
**למה?** ככינוי, צריך משהו אחרי is (לא רק "is")!

### טעות 4: לשכוח a/an עם כינוי
❌ This is book. (ככינוי)
✅ This is a book.
**למה?** ככינוי + יחיד, צריך a/an לפני השם!
אבל: This book... (כתואר - לא צריך a/an)

### טעות 5: לא להבחין בתפקיד
❌ These books are my. (רוצים: "אלה שלי")
✅ These books are mine. (adjective)
✅ These are mine. (pronoun)
**למה?** תואר = עם books. כינוי = בלי books.

## תרגול קצר (1 דקה)

זהו: Adjective או Pronoun?

**1.** This car is fast.
- ✅ Adjective (יש "car" אחרי This)

**2.** That is my house.
- ✅ Pronoun (מיד בא "is" אחרי That)

**3.** These apples are fresh.
- ✅ Adjective (יש "apples" אחרי These)

**4.** Those are expensive.
- ✅ Pronoun (מיד בא "are" אחרי Those)

**5.** This is interesting.
- ✅ Pronoun (מיד בא "is" אחרי This)

## סיכום (30 שניות)

היום למדנו:
- **Adjective** (תואר): **לפני שם עצם** (This book)
- **Pronoun** (כינוי): **עומד לבד** עם is/are (This is)
- **איך לזהות**: יש שם עצם מיד אחרי? Adjective. אין? Pronoun.
- אותה מילה, **שני תפקידים** שונים!
- ככינוי, צריך **a/an** לפני שם יחיד

בשיעור הבא נלמד ביטויים נפוצים עם מילות הצבעה! נתראה!
