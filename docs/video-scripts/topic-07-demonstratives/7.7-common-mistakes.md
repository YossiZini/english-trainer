# 7.7 - טעויות נפוצות | Common Mistakes with Demonstratives

## פתיחה (30 שניות)

שלום! סיימנו את כל הכללים של Demonstratives - מילות ההצבעה.

היום נסכם את כל הטעויות הנפוצות שתלמידים עושים עם This, That, These, Those. אם תיזהרו מהטעויות האלה, השימוש שלכם יהיה מושלם! בואו נתחיל.

## הסבר הכלל (2-3 דקות)

### למה עושים טעויות עם Demonstratives?

**1. בעברית יש פחות אפשרויות**
- בעברית: זה, זאת, אלה (לפי מין ומספר)
- באנגלית: This, That, These, Those (לפי מספר ומרחק)

**2. המרחק לא קיים בעברית באותו אופן**
- בעברית: "הספר הזה" (לא משנה אם קרוב או רחוק)
- באנגלית: This book (קרוב) vs That book (רחוק)

**3. בלבול עם is/are**
- This/That = is (יחיד)
- These/Those = are (רבים)

### טבלת הטעויות הנפוצות ביותר:

| טעות | למה זה שגוי | תיקון |
|------|-------------|-------|
| This books | this = יחיד, books = רבים | **These** books |
| These book | these = רבים, book = יחיד | **This** book / These **books** |
| This are | this = יחיד, צריך is | This **is** |
| These is | these = רבים, צריך are | These **are** |
| This a book | לא צריך a אחרי this | This book / This **is** a book |

## דוגמאות (2-3 דקות)

### טעות 1 - בלבול בין יחיד לרבים:

**❌ שגוי:** This books are mine.
**✅ נכון:** These books are mine.
**למה?** "books" = רבים, לכן צריך These (לא This)!

**❌ שגוי:** These book is good.
**✅ נכון:** This book is good.
**למה?** "book" = יחיד, לכן צריך This (לא These)!

### טעות 2 - בלבול עם is/are:

**❌ שגוי:** This are my friends.
**✅ נכון:** These are my friends.
**למה?** friends = רבים, צריך These are (לא This are)!

**❌ שגוי:** These is my pen.
**✅ נכון:** This is my pen.
**למה?** pen = יחיד, צריך This is (לא These is)!

### טעות 3 - שכחת ההבדל בין קרוב לרחוק:

**❌ שגוי:** Look at this mountain over there!
**✅ נכון:** Look at that mountain over there!
**למה?** "over there" = רחוק, לכן That (לא This)!

**❌ שגוי:** I'm holding that book. (מחזיק בידיים)
**✅ נכון:** I'm holding this book.
**למה?** בידיים = קרוב, לכן This (לא That)!

### טעות 4 - שימוש מיותר ב-a/an:

**❌ שגוי:** This a book is good.
**✅ נכון:** This book is good. (adjective)
**✅ נכון:** This is a book. (pronoun)
**למה?** לא יכול להיות גם this וגם a לפני השם!

### טעות 5 - לא להתאים את הפועל:

**❌ שגוי:** That books is expensive.
**✅ נכון:** That book is expensive. (יחיד)
**✅ נכון:** Those books are expensive. (רבים)
**למה?** books = רבים, צריך Those are!

### טעות 6 - בלבול בתפקיד (תואר/כינוי):

**❌ שגוי:** This is book is interesting.
**✅ נכון:** This book is interesting. (adjective)
**✅ נכון:** This is interesting. (pronoun)
**למה?** לא יכול להיות גם "this" וגם "is" לפני השם!

### טעות 7 - ביטויי זמן שגויים:

**❌ שגוי:** That week I am busy. (שבוע נוכחי)
**✅ נכון:** This week I am busy.
**למה?** שבוע נוכחי = this. שבוע בעבר = that.

## טעויות נפוצות (1-2 דקות)

### קטגוריה 1: טעויות עם מספר (יחיד/רבים)

**❌ שגוי:** That apples are red.
**✅ נכון:** Those apples are red.
**למה?** apples = רבים, צריך Those!

**❌ שגוי:** Those dog is big.
**✅ נכון:** That dog is big.
**למה?** dog = יחיד, צריך That!

### קטגוריה 2: טעויות עם פועל

**❌ שגוי:** This book are good.
**✅ נכון:** This book is good.
**למה?** book = יחיד, צריך is!

**❌ שגוי:** Those is expensive.
**✅ נכון:** Those are expensive.
**למה?** Those = רבים, צריך are!

### קטגוריה 3: טעויות עם מרחק

**❌ שגוי:** These mountains in the distance are high.
**✅ נכון:** Those mountains in the distance are high.
**למה?** במרחק = רחוק, צריך Those!

**❌ שגוי:** That shirt I'm wearing is new.
**✅ נכון:** This shirt I'm wearing is new.
**למה?** אני לובש = קרוב, צריך This!

### קטגוריה 4: טעויות עם a/an

**❌ שגוי:** These a books are mine.
**✅ נכון:** These books are mine.
**למה?** לא צריך a עם these!

**❌ שגוי:** This is book.
**✅ נכון:** This is a book.
**למה?** ככינוי + יחיד, צריך a!

### קטגוריה 5: טעויות בביטויים קבועים

**❌ שגוי:** The morning this I woke up late.
**✅ נכון:** This morning I woke up late.
**למה?** "this morning" הוא ביטוי קבוע!

**❌ שגוי:** Is right!
**✅ נכון:** That's right!
**למה?** הביטוי המלא הוא "That's right"!

## תרגול קצר (1 דקה)

מצאו ותקנו את הטעות:

**1.** ❌ This cars are fast.
- ✅ These cars are fast. (cars = רבים)

**2.** ❌ These is my friend.
- ✅ This is my friend. (friend = יחיד)

**3.** ❌ Look at this mountain over there!
- ✅ Look at that mountain over there! (over there = רחוק)

**4.** ❌ Those book is interesting.
- ✅ That book is interesting. (book = יחיד)

**5.** ❌ This a pen is red.
- ✅ This pen is red. (לא צריך a)

## סיכום (30 שניות)

סיכום הטעויות הנפוצות ביותר:
1. **יחיד/רבים**: להתאים בין This/That (יחיד) ל-These/Those (רבים)
2. **is/are**: This/That = is, These/Those = are
3. **קרוב/רחוק**: This/These = קרוב, That/Those = רחוק
4. **a/an**: לא משתמשים עם demonstratives כתואר
5. **תואר/כינוי**: להבחין בין "This book" ל-"This is a book"
6. **ביטויים**: לשמור על המבנה הקבוע (this week, that's right)

עכשיו אתם מוכנים להשתמש במילות הצבעה בצורה מושלמת! המשיכו לתרגל!
